# Cooked Lad — Landing Page

A tiny, responsive static landing page for **Cooked Lad**, a top-down gun survival game.

## Files

- `index.html` — main landing page
- `privacy.html` — privacy policy
- `styles.css` — monochrome visual theme
- `script.js` — language switcher
- `assets/cooked-lad-logo.png` — game logo

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy

The project is static and can be hosted on GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any normal web host.

## Before publishing

Replace:

`[YOUR CONTACT EMAIL]`

in `privacy.html` with your real privacy/contact email.

The example language switch currently contains English and Spanish. Add or replace translations in `script.js` as needed.

## Markdown copy

The core landing-page copy is intentionally minimal:

> **Get armed. Get surrounded. Get cooked.**

Grab ridiculous guns, mow down ridiculous enemies, and see how long this cooked little lad can survive.
